# Rental subscriptions

Updated 2026-11-01. The rental service is active. The Oregon instance now uses a verified replacement IPv4 entry as primary and retains its existing IPv6 entry as backup.

- Clash / Mihomo: `clash-rental-us-pure.yaml` (requires VLESS/Reality support).
- V2: `v2rayn-rental-us-pure.txt` (Base64 VLESS subscription).
- Existing `nodes.b64` subscription URLs remain supported and serve the same V2 subscription.

The rental identity and Reality parameters remain unchanged. Previously issued fixed IPv6 links remain unchanged; a fixed link does not automatically change its entry address.

Both current client cores passed bounded webpage, download, upload, and multipart checks. This is not a guarantee of account registration, every old client version, or long-term availability.

This repository is public. Its subscription access data is not a private per-customer distribution channel. Owner administration credentials do not belong here.
